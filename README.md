# crypto-data
Hourly public market data for the Crypto Trainer paper-trading project (no trading, no keys except an optional free FRED key).
Files in `data/`: prices, fear_greed, stablecoin_supply, okx_derivatives (funding + open interest), deribit_btc (funding, options put/call and implied volatility), fred_macro (optional), polymarket (prediction-market odds for Fed, Bitcoin and recession questions), news (new headlines from Fed, SEC, CoinDesk, Cointelegraph and GDELT, deduped, titles only), alerts (event flags: 3%+ hourly move, 5-7% daily move, extreme funding, open-interest drop; max 3 per day), errors.
